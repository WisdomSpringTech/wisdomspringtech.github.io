Public business name: WisdomSpringTech

WisdomSpringTech sells a hosted software subscription: onto-kb, a read-only MCP server. Subscribers connect any AI chat app that supports a remote MCP connector to search and read documents in our Google Drive knowledge library.

Claude’s free plan includes at most one custom MCP connector. That single connector is the most a Claude Free account can add. Adding a second custom connector requires a paid Claude plan. onto-kb still costs USD 20 per month even when the chat app’s connector slot is free.

Free plans that currently let you add your own remote MCP connector, checked against vendor documentation on 4 October 2026:

  • Claude Free — at most one custom remote MCP connector on claude.ai, Cowork, and Claude Desktop. Anthropic Help Center.
  • Mistral Free (Vibe / Work) — the account owner can add a custom MCP connector. Mistral does not publish a one-connector cap for Free. Mistral docs.
  • GitHub Copilot Free — MCP is included in Copilot Chat on the free plan. GitHub Copilot plans.

ChatGPT Free does not offer a custom remote MCP connector in OpenAI’s current help documentation. The Cursor Hobby plan does not include MCP; Cursor lists MCP on the Pro plan (Cursor pricing). The Gemini app can add a custom MCP app for a personal Google account that is 18 or over, in the US, in English, with Keep Activity on. Google’s help page does not name a paid Gemini plan for that feature (Gemini Apps Help). Limits change, so confirm in the app before you connect.

Price: USD 20 per month, billed through Stripe Checkout. This website does not collect card numbers and does not show bank account details.

You can cancel the first month at any time before it renews, in the Stripe customer portal. There is no shorter deadline and no free trial. The subscription renews on the same date next month, so the longest first period is 31 days. Canceling stops the next USD 20 charge. It does not refund the first payment. Access lasts until Stripe marks that paid period as ended.

You can set up the MCP connector in your AI chat app only after payment. An AI chat app that already finished Connect keeps working while the subscription is active. That does not send an email and does not charge you again. To continue the same subscription in a different browser, enter the email on your Stripe receipt. Google emails a one-time sign-in link to that inbox. Opening the link does not start a second subscription. Connector setup is not available before payment.
